## Características principales

<CardGrid stagger>
	<Card title="Hardware LoRa de Largo Alcance" icon="setting">
		Nodos con microcontroladores ESP32, módulos transceptores LoRa RFM95 (915MHz) y antenas de 6dBi para enlaces punto a punto.
	</Card>
	<Card title="Motor de IA Local" icon="magnifier">
		Modelos NLP para el triaje automatizado de emergencias y análisis espacial (DBSCAN) para agrupar reportes en el mapa.
	</Card>
	<Card title="Dashboard Resiliente" icon="laptop">
		Panel de control con mapa interactivo de San Miguel, gestión de brigadas, autenticación JWT y alertas de "Sin Conexión".
	</Card>
	<Card title="Gestión Ágil y ODS" icon="list-format">
		Proyecto gestionado mediante Azure DevOps, con un enfoque estricto en los Objetivos de Desarrollo Sostenible (ODS) y calidad de software (QA).
	</Card>
</CardGrid>
